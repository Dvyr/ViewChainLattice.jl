# Lattice chain viewer

Generate a module for simple visualization of lattice confined chains.

The input is given as a Vector of 3-element integer vectors, each containing a lattice vector coordinates. Foe example: [1,1,-1], [1,-1,1], etc.

The chain coordinates are generated by adding these vectors end to end. 

The visualization should contain the chain backbone in bold lines, and 3D integer lattice in thin gray lines.

The 3D plot should be mouse-rotatable.
